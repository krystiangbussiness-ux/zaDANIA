# Zadania z PHP

## Uruchomienie w XAMPP

Skopiuj folder `zadania-php` do `C:\xampp\htdocs\`, uruchom Apache i otwórz [stronę startową](http://localhost/zadania-php/). Jeżeli Apache działa na innym porcie, dodaj numer portu do adresu. Projekty korzystają z PHP i plików tekstowych.

| Folder | Zawartość |
| --- | --- |
| `funkcje_php` | 11 zadań z funkcji PHP |
| `dziennik_ocen` | Formularz ocen i lista wpisów z `dane/oceny.txt` |
| `pliki_php` | Lista elementów z katalogu `dokumenty` i formularz tworzenia plików `.txt` |

Zrzuty ćwiczeń interaktywnych z wynikiem 5/5 (100%) są dołączone do paczki ZIP.

W zadaniu o sile hasła przyjęto, że 8 znaków wystarcza do oceny „mocne”, jeśli są spełnione wszystkie wymagania dotyczące typów znaków. Szyfr przesuwa litery A–Z i a–z o dwa miejsca oraz zachowuje pozostałe znaki.

Przy testowaniu dziennika używaj przykładowych nazwisk. Plik `oceny.txt` utworzy się po pierwszym zapisie.
